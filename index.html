AWS JavaScript DynamoDB

VoteNow – Online Polling System

A cloud-based online polling system developed using HTML, CSS, JavaScript and AWS services. The application allows users to register and participate in polls through a simple and user-friendly interface. It uses Amazon S3 to host the frontend, API Gateway to handle requests, AWS Lambda to process voting operations and DynamoDB to store poll data and voting records. The system supports multiple polls, vote submission and visualization of results using interactive charts. It also includes an admin interface for managing polls and helps make the voting process accessible, organized and efficient.
